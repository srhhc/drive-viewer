# :open_file_folder: דרייב-צפייה — צפייה בתיקיות Google Drive משותפות

אתר סטטי יפה ונוח להצגת תכני וידאו מתוך תיקיות Google Drive משותפות, כולל חיפוש, צפייה בנגן מוטמע, והורדה ישירה.

## :rocket: איך זה עובד

1. **עדכון יומי אוטומטי** — GitHub Actions סורק את תיקיות ה-Drive המוגדרות ומעדכן את רשימת הקבצים
2. **אתר סטטי מהיר** — מוגש דרך GitHub Pages, ללא שרת
3. **חיפוש חכם** — חיפוש fuzzy מהיר בכל הקבצים
4. **נגן וידאו מוטמע** — צפייה ישירה דרך הנגן של Google Drive
5. **הורדה ישירה** — לחיצה אחת להורדה מהמקור

## :gear: הגדרה

### 1. קבלת מפתח API של Google Drive

יש לגשת ל-[Google Cloud Console](https://console.cloud.google.com/), ליצור פרויקט, להפעיל את Google Drive API, וליצור API Key.

### 2. הגדרת Secrets ב-GitHub

הוסף את הסודות הבאים ל-repository (`Settings > Secrets and variables > Actions`):

| Secret | תיאור |
|--------|-------|
| `DRIVE_API_KEY` | מפתח ה-API של Google Drive |
| `DRIVE_FOLDER_IDS` | מזהי תיקיות האב, מופרדים בפסיקים |

### 3. הפעלה

ה-workflow ירוץ אוטומטית פעם ביום. ניתן להריץ ידנית מ-Actions.

## :scroll: הבהרה משפטית

**אנו לא בעלי התכנים המוצגים באתר.** האתר מציג תכנים מתיקיות Google Drive משותפות שהגישה אליהן ציבורית. כל האחריות על התכנים חלה על מעלה הקבצים המקורי. בעלי האתר אינם אחראים לכל נזק, תביעה או הפרת זכויות יוצרים הנובעים מצפייה או הורדה של התכנים המוצגים. הגלישה באתר מהווה הסכמה לתנאים אלו.
